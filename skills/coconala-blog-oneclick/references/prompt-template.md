# ココナラブログ制作・下書き保存プロンプト

以下を実行プロンプトとして使う。角括弧の入力値を埋め、既に決定済みの文言は変更しない。

## 実行プロンプト

あなたは、ココナラブログの記事制作、ChatGPT画像生成、下書き保存を一貫して担当します。確認だけで止まらず、必要情報が揃っていれば検証まで完了してください。ただし、公開は絶対にせず、下書き保存だけにしてください。

### 入力

- 投稿先アカウント：［アカウント名］
- 商品URL：［URL］
- 採用タイトル：［タイトル］
- 本文一行目：［本文一行目］
- 記事メモ：［記事メモ］
- 必ず入れる内容：［必須内容］
- 入れない内容：［除外内容］
- 画像デザイン型：［雰囲気、色、モチーフなど］

### 商品確認

1. 商品URLの現在のページを実際に開き、サービス内容、対象者、提供方法、注意事項、価格など、記事に必要な事実を確認する。
2. 商品ページで確認できない口コミ、資格、実績、件数、残席、期間限定、効果、保証、条件は書かない。
3. 医療、法律、投資などの専門判断を代替する表現や、結果を断定する表現は使わない。

### 本文制作

1. 採用タイトルと本文一行目は一字一句そのまま使う。
2. 本文は日本語で1000〜1400文字を目安にし、温かく自然に販売へつなげる。煽りすぎず、弱すぎない文章にする。
3. 見出しは3つ。各見出しは必ず2行構成にし、ココナラ編集画面では太字・中央寄せを指定する。
4. 本文にMarkdownの `**`、HTMLタグ、制作メモを混ぜない。
5. 本文中に2〜3か所、独立した行で `＜画像挿入：アイキャッチ＞`、`＜画像挿入：A＞`、`＜画像挿入：B＞` を配置する。編集画面では対応画像に置き換える。
6. 読者の悩み、気づき、サービスで得られる支援、利用の流れ、向いている人を自然につなげる。
7. 最後は押しつけないが明確な行動喚起にし、商品URLを最終行へ単独で置く。
8. 太字にする箇所は本文とは別に「太字指定」として列挙する。

### 出力順

1. タイトル
2. 本文
3. 太字指定
4. 画像挿入位置
5. 画像生成プロンプト3通
6. 文字数と事実確認メモ

### ChatGPT画像生成

Codexの画像生成機能は使わない。記事ごとにChatGPTの新しいチャットを1つ作り、ChatGPT側の画像ジェネレーターへ次の3通を順番に送る。1メッセージにつき1画像だけ依頼し、3枚を一括生成しない。これにより、ユーザーがChatGPT上で各画像を編集・再生成できる状態を残す。

全画像の共通条件：

- 1280×670ピクセルの横長画像
- 1枚700KB以下を目標に、必要ならダウンロード後に軽量化
- 1枚の独立画像。コラージュ、分割画面、比較表、複数案のグリッドは禁止
- 過去画像を参照せず、この記事専用の新規画像として作る
- 人物や手を入れる場合は自然な形状にする
- 実画像を目視し、文字化け、余計な文字、透かし、ロゴ、切れ、破綻がないか確認する

#### 1通目：アイキャッチだけ

「次のココナラブログ用アイキャッチ画像を1枚だけ新規生成してください。
記事タイトル：［採用タイトル］
記事テーマ：［記事メモを一文に要約］
デザイン：［画像デザイン型］
サイズ：1280×670ピクセル、横長。
1枚の独立した画像にし、コラージュ、分割、複数案、グリッドは禁止です。
画像内の文字は『［採用タイトル］』だけを、読みやすい日本語で正確に入れてください。ほかの文字、数字、URL、ロゴ、透かしは入れないでください。過去画像は参照せず、この依頼専用の新規画像にしてください。」

#### 2通目：本文画像Aだけ

「同じ記事の本文画像Aを1枚だけ新規生成してください。
役割：読者の悩みや気づきを、［画像デザイン型］の世界観でやさしく表現する。
記事テーマ：［記事メモを一文に要約］
サイズ：1280×670ピクセル、横長。
1枚の独立した画像にし、コラージュ、分割、複数案、グリッドは禁止です。
文字、数字、記号、URL、ロゴ、透かしは一切入れないでください。過去画像は参照せず、この依頼専用の新規画像にしてください。」

#### 3通目：本文画像Bだけ

「同じ記事の本文画像Bを1枚だけ新規生成してください。
役割：サービスを知った後の安心、前向きな一歩、穏やかな解決を、［画像デザイン型］の世界観で表現する。
記事テーマ：［記事メモを一文に要約］
サイズ：1280×670ピクセル、横長。
1枚の独立した画像にし、コラージュ、分割、複数案、グリッドは禁止です。
文字、数字、記号、URL、ロゴ、透かしは一切入れないでください。過去画像は参照せず、この依頼専用の新規画像にしてください。」

アイキャッチにタイトル以外の文字が出た場合、またはA/Bに文字らしきものが少しでも出た場合は不合格として、その画像だけChatGPTで修正する。

### ココナラ下書き保存

1. 保存前に表示アカウントが［アカウント名］と完全一致することを確認する。一致しなければ保存しない。
2. タイトル、本文、画像を入力し、見出しの太字・中央寄せなどはココナラのネイティブ編集機能で設定する。
3. 必ず「下書き保存」を選ぶ。「公開」や公開確認は押さない。
4. 保存後に対象の編集ページを再度開くか再読み込みし、タイトル、下書き表示、アカウント、保存時刻、編集URL、本文、画像を確認する。
5. 太字や中央寄せは再読み込み後も残っている場合だけ完了と報告する。貼り付け時に消えた場合は未完了と明記する。

### 完了報告

- 記事タイトル
- 商品URL
- 本文文字数
- アイキャッチ、画像A、画像Bの生成・目視・700KB以下の状態
- ChatGPT画像チャットURL
- ココナラ下書き編集URL
- 保存確認時刻
- 確認したアカウント
- 「未公開・下書きのまま」であること

画像生成依頼文を作っただけ、保存ボタンを押しただけでは完了としない。実画像と、再読み込み後の下書き状態を確認して初めて完了とする。
